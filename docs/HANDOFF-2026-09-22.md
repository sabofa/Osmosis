## Where things run

- Server: puplirserver, `ssh benif@192.168.5.66`, checkout `/srv/learn/osmosis`, running copy `/opt/osmosis`, service `osmosis` (systemd, port 8081, user `osmosis`), data `/var/lib/osmosis`. Deploy: `cd /srv/learn/osmosis && git pull && bash deploy/install.sh`. Back up first: `sudo -u osmosis sqlite3 /var/lib/osmosis/canonical.db ".backup /var/lib/osmosis/canonical-<date>.db"`. No rsync on the host (the installer's tar path handles that).
- Ben's Windows laptop: local node from this checkout (`data/local.db`, scheduled task "Osmosis Local Node", launcher `data/run-local-node.vbs` runs `server/dist/index.js`). After a rebuild: `curl -X POST localhost:8081/api/admin/restart` or `npx osmosis restart`.

- A `review/` folder and a root `review` npm script exist uncommitted on the laptop: Ben's separate graph-engine session. Leave them.

### Known gaps and deferred minors (all recorded, none load-bearing)
2. `time_limit_sec` is not on the attempt payload; Take fetches the template, so a live (template-less) item never shows a set timer.
3. Exiting a quiz returns to Home, not to the open live session.
4. Narrow-mode review has no graph/document switcher (the test view has one).
5. The panel-view bubble in the test clamps the prompt to four lines.
6. `kind: 'markdown'` shows render LaTeX + line breaks only (RichText is not a markdown renderer). A real markdown renderer would also improve session summaries.
7. Space is `preventDefault`'d while a show is pending, so page-scroll-by-space is gone until acknowledged.
8. `end_session.summary.dont_know` counts responses while the other counts are attempts (equal while one live item = one attempt).
9. `bestGuessCorrect` returns null for both "no guess" and "choice row gone".
10. `readme().node.tools` is `[]` on a local-role node (MCP is not mounted there) while `tools_version` is still reported.
11. `create_questions` writes its idempotency row after the per-question commits: a mid-batch crash then a retry re-creates the committed prefix.
12. `tagPerformanceSource` in `results.ts` duplicates migration 015's view SQL for the learner hold (commented to stay in step).
13. Singular `node_key` stays free-form for legacy items; only `node_keys[]` is grammar-checked; legacy values were backfilled verbatim.
14. `get_due_items` is identity-keyed, so "exclude ephemeral from due items" had nothing to act on.
15. SSE `send` inside `emitter.emit` is unguarded; the events emitter is a module singleton keyed only by session id.
16. The presenter-scope test asserts the concrete list, but the allowlist is `readonly string[]` (a typo is caught by test, not compiler).
17. Taxonomy seeding is not transactional (idempotent resume); `bootstrap("chemistry:gases", {seed:true})` seeds the whole tree but reports the sub-subject's `tag_count`.
18. Terminal REPL Tab completion is best-effort: completion runs ahead of readline's synchronous completer, so the first Tab after a fast keystroke can be empty.
19. Linux local nodes and the server run under systemd as a service user and cannot self-update; `osmosis update` prints the two shell lines instead. Only the Windows-task / shell-run node self-updates.
20. No web component tests (vitest has no DOM); pure helpers are tested, screens were checked in the browser.
21. `osmosis` is `npx osmosis` from the repo; not linked globally.
