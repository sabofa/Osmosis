# Osmosis CLI — one command core, two front ends

Status: built 2026-09-21/22 — all four steps landed (cli-core, the / bar, the osmosis binary, authoring/showing/live/admin). Ben's answers: guided q new with --json; no terminal auth on the LAN; bare names open things.

## Shape

- `cli-core` workspace: pure TypeScript, no DOM, no Node-only APIs. Parser, command registry (typed arguments, completers, help), fuzzy completion.
- Hosts provide `api` (HTTP client to a node), `out` (text / table / JSON), `ui` (navigate, show graph, open document, open theme editor). The app implements all three; the terminal implements `api` + `out` and a `ui` that prints fallbacks or points at the app.
- Grammar: `verb object args…`. `/` opens the palette in the app; `osmosis …` in the terminal. Fuzzy paths (`open bank econ` → `open bank economics`), arrow keys cycle matches, Tab accepts, Enter runs. Bare tag or template names resolve as a last-resort completion.

## Commands (first cut)

Navigate: `open home|bank|library|live|results|settings`, `open bank <tag>`, `open test <template>`, `start <template>`, `open results <tag>`, `open day <date>`, `back`.
Questions: `q <id|search> [--data]`, `q list <tag>`, `q new` (guided; `--json`), `q edit <id>`, `q retire <id>`.
Templates: `template list`, `template <name>`, `template new` (guided), `template start <name>`, `template sql <name>` (draw SQL + JSON, document viewer in the app, printed in the terminal).
Daily: `daily q`, `daily quiz` (terminal: interactive answer loop).
Showing: `graph "<spec>"`, `doc <asset>`, `show text "<markdown>"`.
Live: `session new "<name>" [tag]`, `session list|open|end`, `present <question> [--session]`, `grade <response> <score> ["diagnosis"]`, `ungraded`.
Results: `results [tag]`, `history <date>`, `attempts`, `review <attempt>`.
Settings/admin: `set <key> <value>`, `get [key]`, `theme <name>|edit|new`, `admin reindex|clear <scope>|status`, `sync`.
Meta: `help [command]`, `clear`, `history`.

## Server gaps to fill alongside

Admin routes (reindex FTS, clear attempts/daily/sessions/all with confirmation), template SQL/JSON export, an app-side `present` route, settings reorganisation (Appearance, Behaviour, Sync, Data, About).

## Order

1. Core + app palette: parser, registry, completion, bottom bar; navigation, daily, theme, settings, open.
2. Terminal binary `osmosis` (`--url` / `OSMOSIS_URL`, default localhost:8081): read commands + daily answer loop.
3. Authoring and showing: `q new`, `template new`, `graph`, `doc`, `template sql`.
4. Live and admin: sessions, present, grade, admin routes.
