## Task L1: theme-core layer tokens

### L1.1 — `layerTokens.ts`: pure metadata and helpers (≤150 lines; leaf module, no registry import)
**Files:** create `theme-core/src/layerTokens.ts`, `layerTokens.test.ts`; barrel export.
**Produces (exact, 06 §2.2/§2.3/§2.8):**
```ts
export interface LayerTokenDef {
  token: string; label: string; default: number; floor: number
  floorsBy?: Record<string, number>        // per paper kind
  atLeast?: string                         // another layer token (06 §2.8)
  dialDriven: boolean                      // translucency dial moves its default
}
export const LAYER_TOKENS: readonly LayerTokenDef[]
export interface FloorCtx { paper?: string; minOverride?: number }
export function effectiveFloor(token: string, ctx?: FloorCtx): number            // max(floor, floorsBy[paper] ?? 0, minOverride ?? 0), capped at 1; throws Error on an unknown token
export function clampTokenValue(token: string, value: number | string, ctx?: FloorCtx): number   // clamp to [effectiveFloor, 1]; non-finite / non-numeric input returns the token's default
export function formatAlpha(n: number): string                                    // at most 3 decimals, no trailing zeros: 1 -> '1', 0.92 -> '0.92'
export function dialDefault(token: string, translucency: number): number          // lerp(default, floor, clamp01(translucency)) if dialDriven else default; rounded to 3 decimals
export function resolveLayerAlphas(themeValues: Partial<Record<string, number | string>>, deviceOverrides?: Partial<Record<string, number | string>>, ctx?: FloorCtx): Record<string, number>
//   for EVERY layer token, in dependency order: value = deviceOverrides[t] ?? themeValues[t] ?? default; clamp with clampTokenValue (ctx.paper/minOverride applied only via effectiveFloor, as for any token); then if atLeast: result = max(result, resolved value of the atLeast token). Returns a number for every layer token.
export function assertNoCycles(defs: readonly LayerTokenDef[]): void             // throws Error('layer token cycle: a -> b -> a') — also run once at module load on LAYER_TOKENS
```
**LAYER_TOKENS entries (exact):**

| token | label | default | floor | floorsBy | atLeast | dialDriven |
|---|---|---|---|---|---|---|
| `doc-sheet-alpha` | Document sheet | 1 | 0.55 | — | — | true |
| `doc-surface-alpha` | Document surfaces | 0.9 | 0.6 | — | — | true |
| `doc-media-alpha` | Pictures and PDFs | 0.95 | 0.7 | — | `doc-sheet-alpha` | true |
| `graph-paper-alpha` | Graph paper | 1 | 0.25 | `{ blackboard: 0.85, greenboard: 0.85, whiteboard: 0.85 }` | — | true |
| `graph-grid-alpha` | Grid | 1 | 0.15 | — | — | true |
| `graph-region-alpha` | Region fills | 0.18 | 0.05 | — | — | **false** |
| `callout-alpha` | Callouts | 0.92 | 0.7 | — | — | true |

**Tests:** table sanity (floor ≤ default ≤ 1, every `atLeast` names a layer token); `effectiveFloor` base / board (`graph-paper-alpha` + `paper:'blackboard'` = 0.85) / `minOverride` raises (0.9) but never lowers (0.1 over 0.25 stays 0.25) / unknown paper ignored / unknown token throws; `clampTokenValue` below floor, above 1, string input '0.4', NaN/'abc' ⇒ default, board clamp; `formatAlpha` table (1, 0.92, 0.5, 0.125, 0.3333→'0.333'); `dialDefault` dial 0 = default, dial 1 = floor, dial 0.5 midpoint, region unaffected, clamps the dial; `resolveLayerAlphas`: defaults when empty; theme sheet 0.6 + theme media 0.65 ⇒ media 0.65 (≥ sheet); sheet 1 ⇒ media 1 whatever the token says; **device override of the sheet to 0.9 raises media from 0.7 to 0.9**; device override wins over theme; paper board raises paper alpha to 0.85; out-of-range values clamped; `assertNoCycles` throws on a synthetic a→b→a list and passes for LAYER_TOKENS; barrel export.
**Acceptance:** theme-core suite + typecheck green.

### L1.2 — registry tokens, clamp, dial defaults, ownership (≤150 lines)
**Files:** `theme-core/src/registry/types.ts` (TokenDef `min?`/`max?`), `registry/resolver.ts` (clamp), new `registry/alpha.ts` (the six new tokens), `registry/engines.ts` (`graph-region-alpha` gains min/max from LAYER_TOKENS), `registry/index.ts`, `layers.ts` (shared exception), tests, regenerated `docs/theming/TOKENS.md`.
**Rules:**
- `TokenDef` gains `min?: number; max?: number`. In `createResolver` an override for a token that has `min`/`max` is validated as a number (non-numeric ⇒ `ResolveError` as before) and then **clamped** into [min, max] and formatted with `formatAlpha` — never thrown for range. Derived values are clamped the same way. Other tokens unchanged.
- New tokens in `registry/alpha.ts` (type `number`, `modeDependent:false`, `meaning` written for an AI author, default derived by `formatAlpha(dialDefault(token, ctx.dials.translucency))`): `doc-sheet-alpha`, `doc-surface-alpha`, `doc-media-alpha` (group `document`); `graph-paper-alpha`, `graph-grid-alpha` (group `graph`); `callout-alpha` (group `surface`). `min` = the LAYER_TOKENS floor, `max` = 1, read from `LAYER_TOKENS` (single source). `graph-region-alpha` keeps its derive `'0.18'` but gains `min: 0.05, max: 1`.
- `ownerOf`: add `doc-sheet-alpha` to the shared set; the other five follow their groups to the ambience layer (no change needed); update the ownership tests' expectations and the “all tokens have an owner” test.
- Provenance: a theme whose dial ≠ 0 shows these as `dial`.
**Tests:** all six resolve in both modes with the table defaults at dial 0; dial 1 ⇒ the floors (region stays 0.18); dial 0.5 midpoint; an override below the floor clamps to the BASE floor (e.g. `callout-alpha: '0.1'` ⇒ `'0.7'`) without throwing; override above 1 ⇒ `'1'`; override `'abc'` still throws `ResolveError`; override `'0.8'` stays; `ownerOf('doc-sheet-alpha') === 'shared'`, `doc-surface-alpha`/`graph-paper-alpha`/`graph-grid-alpha`/`graph-region-alpha`/`callout-alpha`/`doc-media-alpha` ⇒ `ambience`; compose: a workspace theme override of `doc-sheet-alpha` survives, an ambience dial default does not beat it, and a workspace override of `doc-surface-alpha` lands in `ignored`; **no existing token's resolved value changes** for the four ambience built-ins (compare light/dark maps before/after, minus the six new keys); `TOKENS.md` regenerated (`npm run docs --workspace=theme-core`), drift test green, token count +6 wherever asserted; `emit` guard still passes (numbers are safe strings).
**Acceptance:** suites + typecheck green; LAYER_TOKENS is the only place the numbers appear (grep the registry for `0.55`/`0.85` literals — none).
