## T8.2 — `review/src/styles/SettingsPanel.tsx` + `LayerSelector.tsx`
```tsx
export interface SettingsPanelProps {
  specs: readonly SettingSpec[]                       // any list (REGISTRY, filtered)
  values: ReadonlyMap<string, SettingValue>           // this layer's own values
  inherited: ReadonlyMap<string, SettingValue>        // the value from the layers below, shown when the layer has none
  meanings?: (path: string) => string | undefined     // from GUIDE (prose) — passed in, never imported by the panel
  ratings?: (path: string) => string | undefined      // from sweep.json, optional
  onChange: (path: string, value: SettingValue | undefined) => void   // undefined = clear back to inherited
}
```
- Group by `spec.group`, in collapsible sections.
- **The controls:**
  - a number: a slider plus a number box, honouring min, max, step and `integer`;
  - a choice: a select;
  - a colour: `<input type=color>`;
  - a curve: a small read-only SVG preview.
- An inherited value shows dimmed, with a "set" affordance. A set value has a clear (×) button.
- The meaning and rating appear on hover (`title`).
- **`LayerSelector`:** `{ layer: EditedLayer; graphTypes: readonly GraphType[]; onChange(layer) }`, where `type EditedLayer = { kind: 'theme' } | { kind: 'themeType'; graphType: GraphType } | { kind: 'document' }`.
